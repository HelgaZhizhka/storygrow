# STO-15 — два текста после уточнения задания автору

2026-10-01. Владелец согласовала продолжение здесь с Codex: уточнение автора, ограниченный запуск, чтение, затем внедрение принятого подхода. Без Claude/других агентов. Для этого запуска Codex установил и сообщил предел $0.30: два author + два safety, без автоматического продолжения. Это не новый поиск моделей.

## Замороженные условия

- GPT-5-2025-08-07, Алиса 6 лет, 5–6 / virtue: Доброта, затем Самостоятельность. Пользовательские задания дословно из case-1/case-3 опыта 2026-09-27. Нет готовых сюжетов, образцов, Сутеева или редактора.
- System = литературное ядро 2026-09-27 + ровно два уточнения из [плана](../2026-10-01-stage1-resume.md) + прежняя safety-граница дословно. Полные запросы в requests.json, оригиналы старых опытов не изменяются.
- WholeStorySchema, гейты и отдельная safety gpt-4o-2024-08-06 прежние. GenerateObject + Zod, выход 10000/2000, timeout 240 секунд, retries 0, serviceTier default. Temperature/reasoning effort не заданы, как раньше. Нет craft-judge или редактирования.
- Перед каждым HTTP запросом оценка UTF-8 bytes полного JSON + 1024 input tokens запаса и весь output limit; сумма с uncached usage не превышает $0.30. Это консервативная оценка, не гарантия API-биллинга. Неизвестный usage/технический сбой прекращает запуск, SENT не повторяется. Даже отвергнутые тексты сохраняются.
- Официальные тарифы перепроверены 2026-10-01: [GPT-5](https://developers.openai.com/api/docs/models/gpt-5) $1.25/$10 и [GPT-4o](https://developers.openai.com/api/docs/models/gpt-4o) $2.50/$10 за миллион input/output tokens. Actual cost — по LangFuse, не по предзапросному резерву.

## Чтение и границы выводов

Каждый текст читаем целиком без ручной правки. Проверяем желание, препятствие, собственное решение и завершённый результат; кто где находится, предметы/реплики и переходы; посильность действий; обычный живой язык и конкретное название. Отдельно — нет ли анкетного возраста и инструкции. Цель проявляется в поступке и влияет на исход, помощь допустима. Интерес и желание дочитать оценивает владелец; гейты/safety не доказывают их.

Вердикт Codex: кандидат для чтения / существенная редактура / отвергнуть, с конкретными эпизодами. Две разные цели не дают статистики повторяемости. Без контрольной пары не утверждаем причинный эффект двух уточнений. Не объявляем gold до принятия владельцем и не идём к PDF только потому, что вызовы прошли.

## След и область изменений

Отдельный research runner на прежней механике, offline проверки замороженных входов/модели/бюджета и запрета повтора. Вход форматируется до freeze, manifest фиксирует SHA и зависимости. Все запросы, ответы, usage и started/error файлы сохраняются; четыре traces должны получиться обратно HTTP 200 с GENERATION model/usage. Нет Book/StoryEval, картинок/PDF, изменения production/harness prompt или автоматической следующей серии. После чтения записываем результат в report.md и STO-15.
