# STO-15 — «Прятки»: принятый редакционный эталон

Дата: 2026-09-25. Возраст: 5–6. Цель: «Доброта». Арка: добродетель.

## Статус и происхождение

Сказка написана и последовательно отредактирована локальным Codex в разговоре с владельцем. Это не неизменённый результат `eval:whole-story`, не новый API-эксперимент и не доказательство качества автоматического пайплайна. Платных API-прогонов для этой записи не проводилось; отдельного safety-вердикта, LangFuse trace, Book/StoryEval и PDF нет.

Владелец выбрала этот сюжет из трёх, попросила завершить развязку, сделать цель заметной и добавить вопросы. Оценка последней полной версии: «Вроде как неплохо»; затем «в целом неплохо». Она отдельно попросила сохранить «Ты и в прошлый раз обещал»: друзья уже терпели повторяющееся поведение, а Алиса наконец помогла Зайцу справиться со страхом в игре.

**2026-09-26: владелец приняла текст с исправлением перехода** — «хорошо фиксируем прятки и двегиемся дальше». Это первый принятый редакционный эталон (gold) для 5–6 / Доброта / добродетель. Он создан совместной редактурой в чате. Принятие не закрывает требование STO-15 о качестве генерации через harness. Задача остаётся In Progress, PR #410 — draft, без слияния.

- [Полная версия до последней проверки](story-before-review.md) — сохранённый текст из разговора; более ранние варианты и обсуждение остаются в чате.
- [Уточнённая версия для чтения](story.md) — 464 слов по подсчёту кириллических слов с внутренними дефисами, без заголовка и вопросов. Это редакционный подсчёт, не запуск продуктового гейта.

## Что уточнено

1. Перед вторым раундом Белка явно начинает считать; указано, что Мышонок бежит к лопухам.
2. Найденный Мышонок явно присоединяется к поискам Белки.
3. Перед третьим раундом Мышонок явно начинает считать.
4. Белка прячется за елью, чтобы не путать её укрытие с деревом для счёта.
5. Найденные Алиса и Белка возвращаются к дереву для счёта.

6. После замечания владельца исправлено ошибочное «остался возле пня»: Заяц стоит один посреди поляны, Алиса оглядывается и возвращается. Убраны палочка и связанное с прежним положением «провёл лапой по пню»; вместо него — «Заяц помолчал». Предыдущая проверка пропустила это несоответствие; исправление сохранено 2026-09-26.

Предыстория «Ты и в прошлый раз обещал» сохранена. Сюжет, развязка и три вопроса не изменены.

## Цель и критерии чтения

Доброта здесь: заметить трудность друга и помочь ему участвовать в общей игре. Главная героиня — Алиса: сердится → узнаёт причину → предлагает спрятаться вместе → её помощь позволяет продолжить игру всем. Перемена Зайца — следствие её поступка, а не подмена цели на «смелость». Это один удачный опыт персонажа, не утверждение об устранении детских страхов книгой.

Сохраняем как редакционные ориентиры: знакомое ребёнку занятие; понятная причина конфликта; убедительное раздражение друзей; помощь конкретным действием; завершённое последствие; вопросы, которые обсуждают события, а не заменяют развязку. Не превращать Зайца, прятки, страх или исключение из игры в обязательный шаблон других целей. Не вставлять полный текст в промпт автора без отдельного эксперимента.

Вопросы вынесены после сказки; их размещение в PDF пока не реализовано. Решение убрать упоминание Сутеева из будущего эксперимента обсуждено, но текущие production/harness-промпты не изменены.

Это подготовка примеров для будущей проверки генерации, а не сам эксперимент повторяемости. Платный запуск автоматически не предусмотрен. Вёрстка — после принятия текста. Архив занятий владельца остался локально и в эту запись не скопирован.
