# STO-15 — Qwen против GPT-5, шесть текстов

Владелец согласовала 6 авторских вызовов + 6 проверок safety, общий лимит $0.50. Никаких подписок, серверной аренды, изображений, ручного редактирования или повторной генерации. Условия записаны до первого вызова 2026-09-30. Это исследование, production не меняется.

## Входы и сравнение

Три пары: Доброта / 3–4 / virtue; Самостоятельность / 5–6 / virtue; Честность / 5–6 / flaw. Алиса 4 или 6 лет. Точные system/user в requests.json; внутри каждой пары идентичны. Литературное ядро опыта 2026-09-27 адаптировано к возрасту и арке, прежняя safety-граница приложена дословно. Нет Сутеева, золотых примеров, готового замысла, страниц или заданного числа попыток. Вопросы не входят в схему этого опыта.

Qwen/Qwen3-235B-A22B-Instruct-2507 через HF, явно провайдер novita; gpt-5-2025-08-07 через OpenAI. Порядок Q/G, G/Q, Q/G. Один ответ на условие; GPT-5 — контроль прежнего исследовательского автора, не утверждение о текущей production-модели. Qwen temperature=0.7, остальные параметры по умолчанию; GPT-5 temperature/effort по умолчанию прежнего harness. Это практическое сравнение конфигураций, не изолированное сравнение весов при равных вычислениях. Различаются API chat/responses и доступный бюджет выхода (Qwen 4000, GPT-5 10000 с reasoning). Нет настройки параметров по результатам.

generateObject + прежняя WholeStorySchema, retries=0, timeout=240s. Safety для каждого результата — gpt-4o-2024-08-06, прежний prompt/schema, output 2000. Нет craft-judge или автоматического редактора. Провал длины или литературного качества не запускает повтор; ошибка API/schema/usage останавливает опыт, сохраняет запрос/ответ и не допускает молчаливого fallback. Повторный запуск отказан по run-started.json.

## Бюджет и доказательства

Тарифы за миллион токенов: GPT-5 $1.25/$10 input/output; safety GPT-4o $2.50/$10; Qwen Novita через HF $0.09/$0.58. Перед запуском GET каталога проверяет тариф Novita не выше зафиксированного. Ссылки: https://developers.openai.com/api/docs/models/gpt-5, https://developers.openai.com/api/docs/models/gpt-4o, https://router.huggingface.co/v1/models .

Перед каждым HTTP-вызовом guard оценивает верхний расход: UTF-8 байты полного JSON + 1024 на input, полный разрешённый output, плюс уже потраченная сумма без скидки кеша. Следующий запрос запрещён при превышении $0.50. Это консервативная оценка токенизации, не банковский лимит. При неизвестном usage/ошибке дальнейших вызовов нет. Ключи берутся через ConfigService, заголовки авторизации не сохраняются. Wire JSON/ответы, usage, manifest/source hashes, LangFuse traces сохраняются; модель Qwen может не иметь автоматического тарифа LangFuse, тогда её стоимость считается по usage и опубликованным ставкам и явно называется расчётной.

## Чтение и критерии до результатов

Сначала самостоятельное чтение всех шести, без изменения текста. Пользователю — пакет с нейтральными метками A/B внутри каждой пары, ключ моделей отдельно в отчёте. Codex имеет доступ к происхождению, поэтому его оценка не объявляется слепой.

Смотрим: хочется ли дочитать; естественность русского и реплик; понятная последовательность и развязка; правдоподобие действий ребёнка; цель через выбор героини; соответствие возрасту. Длина/safety — отдельные результаты, не доказательство увлекательности. Одна сказка на ячейку не позволяет доказать победителя, разнообразие или надёжность для production. Тексты не объявляются gold до владельца.

## Прерывание и ограниченное продолжение

Исходный процесс исчез после отправки case-3 (GPT-5 / самостоятельность). Case-1/2 и обе safety завершены; у case-3 только started/wire-request, нет ответа или ошибки. Процесс отсутствует в системе; LangFuse lookup его trace вернул 404. Причина завершения процесса не установлена; совпало с прерыванием сессии, но причинность не доказана.

Повтор case-3 запрещён. Отдельный resume.cjs продолжает только ещё не отправленные case-4/5/6, проверяет точный префикс результата и отсутствие их started-файлов; повтор самого resume запрещён. В общий бюджет включена ПОЛНАЯ верхняя оценка отправленного неизвестного запроса ($0.10905375 — точное значение в wire-request), плюс известные расходы. Поэтому максимум шесть author HTTP-запросов, из них пять доступных текстов; safety пять, а не шесть. Полноценная пара по самостоятельности не получится. Неполнота явно отражается в чтении/отчёте; не скрываем пропавший запрос и не называем резерв фактическим расходом.
