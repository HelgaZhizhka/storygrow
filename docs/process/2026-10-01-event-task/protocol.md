# STO-15 — проба задания на развитие события

2026-10-01. Владелец попросила пробовать новое задание: качество инструкции оценит по сказкам. Codex сообщил ограничение $0.30 за два author + два safety, без повторов. Без Claude, других агентов или изменения production.

## Условия до запуска

- Автор GPT-5-2025-08-07, safety GPT-4o-2024-08-06. Два случая: Доброта, затем Самостоятельность; Алиса 6, возраст читателя 5–6, virtue. Те же goal descriptions/arc и исходные user inputs, что в прежней паре.
- System полностью заменяет литературное ядро на раздел «Литературное ядро» [подготовленного задания](../2026-10-01-story-causality/author-task.md), затем дословная прежняя safety boundary. Старое ядро и два прошлых уточнения отдельно не добавляются. В user input добавлены возраст читателя и 350–550 слов: новое ядро ссылается на заданные параметры. Это документированное уточнение входа, не полностью тождественная контрольная пара.
- Нет готового замысла/образца/Сутеева, результатов соседнего вызова, редактора, числового judge или нового планировщика. WholeStorySchema, runTextGates и binary safety prompt прежние. GenerateObject + Zod; выход 10000/2000, timeout240s, retries0, tier default; temperature/reasoning effort provider default как раньше.
- Перед отправкой полного HTTP JSON guard оценивает UTF-8 bytes +1024 input tokens запаса, плюс весь выход по известным тарифам ($1.25/$10 GPT-5, $2.50/$10 GPT-4o за миллион tokens, официальные страницы проверены 1 октября в предыдущей пробе). Остаток с uncached usage не должен превышать $0.30. Это консервативная оценка, не гарантия биллинга; фактический расход проверяем по LangFuse. Любая техническая ошибка/неизвестный usage останавливает серию. SENT не повторяется, неудачные тексты не выбрасываются.

## Чтение и вывод

Показать все два оригинала без ручной правки. Проверить связность событий и предметов/участников, желание/решение/исход, посильность действий и проявление цели, затянутость, естественный язык/название. Отдельно гейты/safety; проход не равен интересной сказке. Последний вердикт о том, хочется ли читать, за владельцем. Никакого gold или stage1 completion автоматически.

Ровно два разных случая, без одновременно запущенного контроля. Сравнение с предыдущей отвергнутой парой — качественное чтение отдельных результатов, не причинный A/B эффект, статистика разнообразия или переносимости. Если снова плохо, сохранить плохое и остановиться, не скрывать недостатки редактурой и не запускать новые попытки из этого протокола.
